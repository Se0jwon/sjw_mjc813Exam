## 인텔리제이에서 tomcat 연동 하기
1. apache tomcat 10버전 이상(jdk17이상) zip 다운로드 압축해제한다. 경로를 기억해야 한다.
2. 인텔리제이 setting > plugin > smart tomcat 찾아서 install
3. 인텔리제이 setting > Tomcat Server 메뉴에서 1번에서 다운로드한 tomcat 을 Add(+) 한다.
4. 인텔리제이 Run > Edit Configuration 메뉴에서 +(Add) 버튼 클릭한다.
5. +(Add) 버튼 클릭 > Smart Tomcat 선택 > Configuration 에서 해당 프로젝트로 설정
5-1. Context Path 는 Context 명을 의미한다. 루트는 / 하나이다. 포트는 현재 호스트에서 사용 안하는 포트번호 입력
6. Debug/Run 모드로 실행한다.

## HRD 소스 분석하기 (UI 화면에서 Data까지 분석, Data에서 UI화면까지 분석)
1. JavaVO, JavaBean, JavaDto, JavaEntity, .. 객체를 먼저 확인 분석 => 테이블의 구조
2. JavaBean 객체가 DB에서 CRUD 가 발생하므로 테이블의구조 분석이 끝나면 DB 데이터를 웹서버와 read,write 부분을 찾아야 한다.
2-1. 옛날에는 Data Access Object 라고 DAO 에서 처리했었다. DAO 에는 CRUD 가 존재한다.
3. 비지니스로직에 존재하는 클래스를 찾아야 한다. 그러나 HRD 에는 그런 클래스가 없다.
4. 웹컨트롤러에서 웹브라우저의 요청과 응답하는 CRUD 메소드를 찾아야 한다.
5. 웹브라우저의 화면에 해당하는 CRUD 를 찾아야 한다.

## 웹서버의 MVC 패턴
- 웹서버에서 데이터를 처리할때 MVC 패턴 레이어구조를 사용하는 스프링프레임워크의 시작
- Model, View, Controller 3개의 레이어구조로 나눠서 데이터를 처리하고 전달하고 로직을 처리한다.
- Model : Data 의 기본 구조, HashMap 을 제거해서 Java Vo, Bean, Dto, Entity 자바 클래스를 이용한다.
	CUD : Model 객체가 SQL 의 insert, update, delete 문장의 데이터 객체
	R : SQL 의 select 문장의 튜플들이 Model 객체로 변환해서 데이터를 전달받는다.
- View : 화면의 기본 구조 (화면에 출력할 데이터, 입력하는 데이터 Model)
	옛날에는 html, JSP, ASP, PHP, ..
	요즘에는 html/css/js, Vue.js, React, Thymeleaf, FreeMarker, Mustache, ... 화면템플릿
- Controller : Servlet 을 근간으로 클라이언트의 요청, 응답을 처리한다.
	Controller 에서 Service 호출하고 Server 에서 DAO 호출하여 데이터를 처리한다.

- Authorize : 인증된 유저의 권한, 롤(ROLE_ADMIN, ROLE_USER)
- Filter : Servlet 라이브러리에서 사용하는 개념, 
	서버에만 적용
	클라이언트의 요청이 들어오면 Filter 에서 해당 요청을 먼저 실행하거나 나중에 실행하도록 가로채서 실행하는 메소드를 만들수 있다.
	FilterChain : 마치 체인사슬처럼 여러개 필터를 계속 실행할수 있도록 개발합니다.

## Cookie 로그인
- 아이디와 암호가 맞을경우에는 새로운 Cookie 를 response 응답으로 만들어준다.
- 새로운 Cookie 에는 로그인 한 사용자의 Nickname, id, httpOnly
- 로그인한 이후에 자원에 접근할때는 @ControllerAdvice 를 사용할 수 있다. 또는 Filter 를 사용할 수 있다.
- 로그아웃은 키값의 쿠키의 setMaxAge(0) 설정한다.

## Session 로그인
- 아이디와 암호가 맞을경우에는 기존 Java Session 에 키/값으로 사용자의 id, Nickname 을 서버에 저장한다.
- 로그아웃은 invalidate(); 메소드로 Java Session 을 비활성화 시켜서 Java 가 새로운 SessionID 로 http 접속을 받아들이도록 한다.
